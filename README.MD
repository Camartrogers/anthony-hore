# Anthonyhore.com

Anthonyhore.com is a professional portfolio website for Anthony Hore, a Brand and Creative Director specializing in marketing. The site showcases Anthony's work to potential employers and contractors through a visually striking and highly customizable layout.

## Live Site

The portfolio is live and can be viewed at:  
[https://anthonyhore.com](https://anthonyhore.com)

## Features

- **Customizable Project Layout**: Flexible layouts tailored to effectively display diverse projects.
- **Video Integrations**: Seamless support for Vimeo videos and other embedded media.
- **Smooth User Experience**: Powered by Lenis smooth scroll for an intuitive, flowing navigation experience.
- **Responsive Design**: Ensures a consistent and visually appealing presentation across all devices.

## Technologies Used

This project leverages modern web technologies to deliver a fast and interactive user experience:

- **[Tailwind CSS](https://tailwindcss.com/)**: For utility-first, responsive styling.
- **[Alpine.js](https://alpinejs.dev/)**: Lightweight JavaScript framework for interactivity.
- **[Lenis](https://github.com/studio-freight/lenis)**: Smooth scrolling library.
- **[Vimeo Player API](https://developer.vimeo.com/player)**: To integrate and manage video playback dynamically.

## Getting Started

### Prerequisites

Ensure you have the following installed on your system:

- [Node.js](https://nodejs.org/) (LTS version recommended)
- npm (comes with Node.js)

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/anthonyhore.com.git
   ```
2. Navigate to the theme folder:
   ```bash
   cd /path/to/wp-content/themes/anthonyhore
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Development

To start the development environment with live reloading:

```bash
npm run watch
```

## Production

To build the project for production:

```bash
npm run production
```
